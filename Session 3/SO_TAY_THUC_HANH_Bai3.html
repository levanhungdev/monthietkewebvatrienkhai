Phần 1. CSS cơ bản

Slide 7–8

Xuất phát: trang chỉ có HTML

CSS (Cascading Style Sheets) là ngôn ngữ định dạng cho trang HTML. HTML là khung xương: quyết định trang có nội dung gì và nội dung đó mang ý nghĩa gì (tiêu đề, menu, đoạn văn). CSS là phần trình bày: màu sắc, font chữ, khoảng cách, bố cục.

Tách CSS ra khỏi HTML giúp mã dễ quản lý: một file CSS dùng cho nhiều trang, đổi giao diện mà không phải sửa nội dung.

Thực hành

  • Giải nén bai3-css-starter.zip. Không mở file trực tiếp bên trong file zip.
  • Mở thư mục bằng VS Code (File > Open Folder), mở css/style.css.
  • Mở index.html bằng Chrome hoặc Edge, cuộn qua toàn trang.

Kết quả cần thấy. Trang hiển thị với kiểu mặc định của trình duyệt: chữ đen, nền trắng, không có bố cục.

Tự kiểm tra. Nếu xoá file CSS, trang có mất nội dung không?

Không. Trang chỉ mất phần trình bày, nội dung HTML vẫn còn nguyên.

Slide 9

Ba cách thêm CSS

Có ba cách đưa CSS vào trang:

  • Inline: thuộc tính style trên từng thẻ. Nhanh nhưng phải lặp lại ở từng thẻ, khó sửa về sau.
  • Internal: thẻ <style> trong <head>. Chỉ có tác dụng trong một trang.
  • External: file .css riêng, liên kết bằng <link>. Nhiều trang dùng chung một file. Đây là cách dùng trong môn học.

Khi các cách cùng định dạng một thuộc tính, khai báo được đọc sau sẽ được áp dụng.

Sửa trong index.html

1. Inline – sửa thẻ p#inline-demo trong index.html

<p id="inline-demo" style="color: red;">Dòng này dùng để thử inline CSS.</p>

2. Internal – thêm vào <head>

<style>
  h1 { color: green; }
</style>

3. External – thay dòng comment SLIDE 9 trong <head>

<link rel="stylesheet" href="css/style.css">

Gõ vào css/style.css

Thêm mới Mục 0 · Thiết lập chung

h1 {
  color: #1f3c88;
}

Lưu file (Ctrl+S) rồi tải lại trang (F5).

Sau đó. Xoá thuộc tính style inline và thẻ <style>. Từ đây chỉ dùng file external.

Kết quả cần thấy. Nếu thẻ <style> đứng sau <link> thì tiêu đề màu xanh lá (internal thắng vì viết sau). Đổi thứ tự hai thẻ để thấy thứ tự cũng là cascade.

Tự kiểm tra. Thêm thẻ link xong mà trang không đổi. Kiểm tra gì đầu tiên?

Đường dẫn href: file nằm trong thư mục css/ nên phải là css/style.css. Kiểm tra thêm tên file có bị thành style.css.txt không.

Cấu trúc một quy tắc

Ba loại bộ chọn cơ bản: theo thẻ (p), theo class (.demo ứng với class="demo"), theo id (#intro ứng với id="intro").

Thêm mới Mục 1 · Quy tắc và bộ chọn

  color: red;
  background-color: yellow;
}

Lưu file (Ctrl+S) rồi tải lại trang (F5).

Kết quả cần thấy. Dòng “chọn theo class demo” có chữ đỏ, nền vàng.

Cùng làm. Xoá dấu ; sau red: khai báo kế tiếp bị bỏ qua. Trả lại dấu chấm phẩy.

Tự kiểm tra. Trong .demo { color: red; }, đâu là selector, property, value?

.demo là selector, color là property, red là value.

Slide 14

Bốn cách viết màu

color đổi màu chữ, background-color đổi màu nền. Bốn cách viết màu:

  • Tên màu: red, orange.
  • HEX #RRGGBB, mỗi cặp ký tự từ 00 đến FF. Rút gọn được khi từng cặp giống nhau: #666666 → #666.
  • RGB: mỗi kênh đỏ, lục, lam từ 0 đến 255.
  • RGBA: thêm kênh alpha từ 0 (trong suốt) đến 1 (đục hoàn toàn).

Alpha trong rgba chỉ làm trong suốt màu đó; thuộc tính opacity làm trong suốt cả phần tử.

Gõ vào css/style.css

Thêm mới Mục 1 · Quy tắc và bộ chọn

.c-named {
  color: red;
}
.c-hex {
  color: #ffa400;
}
.c-rgb {
  color: rgb(0, 0, 0);
}
.c-rgba {
  color: rgba(0, 0, 0, 0.5);
}

Lưu file (Ctrl+S) rồi tải lại trang (F5).

Kết quả cần thấy. Dòng RGBA nhạt hơn dòng RGB vì alpha 0.5.

Cùng làm. Đổi #ffa400 thành dạng rút gọn #fa0: màu không đổi.

Slide 17

width, height, min, max

width, height đặt kích thước. min-width, min-height là giới hạn dưới; max-width, max-height là giới hạn trên.

Phần trăm của width tính theo chiều rộng khối chứa. Phần trăm của height chỉ có tác dụng khi khối chứa có chiều cao xác định.

Nên ưu tiên max-width thay cho width cố định để khối co lại được trên màn hình hẹp.

Gõ vào css/style.css

Thêm mới Mục 2 · Kích thước, nền, đơn vị

.box-fixed {
  width: 300px;
  height: 120px;
  margin-bottom: 1rem;
  background-color: #e8f0ff;
}
.box-fluid {
  width: 100%;
  max-width: 600px;
  min-height: 120px;
  background-color: #fde7c2;
}

Lưu file (Ctrl+S) rồi tải lại trang (F5).

Lưu ý. margin-bottom chỉ để tách hai hộp, sẽ học ở slide 22.

Kết quả cần thấy. Thu hẹp cửa sổ: hộp cố định bị tràn, hộp linh hoạt co theo.

Tự kiểm tra. Vì sao hộp width: 300px bị tràn khi màn hình hẹp?

Width cố định không co lại; khối chứa hẹp hơn 300px thì hộp vượt ra ngoài.

Slide 18

Ảnh nền

Năm thuộc tính nền: background-color (màu nền), background-image (ảnh nền), background-repeat (lặp ảnh), background-position (vị trí ảnh), background-size (kích thước ảnh).

cover phủ kín khung, có thể cắt ảnh; contain hiện đủ ảnh, có thể còn khoảng trống.

Đường dẫn trong url() tính từ vị trí file CSS. File style.css nằm trong thư mục css/, nên phải đi ra ngoài một cấp: ../images/bg.jpg.

Gõ vào css/style.css

Thêm mới Mục 2 · Kích thước, nền, đơn vị

.banner {
  min-height: 160px;
  background-color: #e8f0ff;
  background-image: url("../images/bg.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}

Lưu file (Ctrl+S) rồi tải lại trang (F5).

Kết quả cần thấy. Ảnh nền phủ kín khung “Chào mừng”.

Cùng làm. Đổi cover thành contain: hai bên xuất hiện khoảng trống màu #e8f0ff. Trả lại cover.

Tự kiểm tra. Viết url("images/bg.jpg") trong style.css thì sao?

Ảnh không hiện, vì trình duyệt tìm css/images/bg.jpg – thư mục không tồn tại.

  • vw, vh: 1% chiều rộng, chiều cao khung nhìn.

Với khối chứa rộng 400px và cỡ chữ gốc 16px, width: 50%; padding: 1rem; cho hộp rộng 200px, padding 16px mỗi phía.

Cùng làm. Đổi 50% thành 75%, rồi thu hẹp cửa sổ. Giữ lại 50%.

Slide 20

em và rem

em và rem khác nhau ở mốc tham chiếu. Với font-size, em tính theo cỡ chữ phần tử cha, rem luôn tính theo phần tử html.

Ví dụ: .parent có font-size 20px → .em (2em) = 40px; .rem (2rem) = 2 × 16 = 32px.

Với padding, margin, em tính theo cỡ chữ của chính phần tử. Nên dùng rem cho cỡ chữ và khoảng cách chung để dễ kiểm soát.

Gõ vào css/style.css

Thêm mới Mục 0 · Thiết lập chung

html {
  font-size: 16px;
}

Thêm mới Mục 2 · Kích thước, nền, đơn vị

.parent {
  font-size: 20px;
}
.em {
  font-size: 2em;
}
.rem {
  font-size: 2rem;
}

Lưu file (Ctrl+S) rồi tải lại trang (F5).

Lưu ý. html { font-size: 16px; } chỉ để ghi rõ mốc tính toán. Trong dự án thật nên giữ mặc định của trình duyệt để tôn trọng cài đặt cỡ chữ của người dùng.

Kết quả cần thấy. Dòng 2em = 40px, dòng 2rem = 32px.

Cùng làm. Đổi .parent thành 24px: chỉ dòng em đổi (48px). Trả lại 20px.

Tự kiểm tra. Đổi .parent thành 24px, dòng 2em và 2rem bằng bao nhiêu?

2em = 48px; 2rem vẫn là 32px.

  color: #172033;

Lưu file (Ctrl+S) rồi tải lại trang (F5).

Kết quả cần thấy. Thẻ Giới thiệu có viền xanh, bo góc.

Cùng làm. Đổi solid → dashed; đổi radius 0 rồi 24px. Trả lại solid và 12px.

Slide 22

Margin và căn giữa khối

margin là khoảng cách bên ngoài viền. Viết 1 đến 4 giá trị theo chiều kim đồng hồ, bắt đầu từ cạnh trên: trên – phải – dưới – trái. Hai giá trị: trên/dưới | trái/phải.

margin: 16px auto; căn giữa khối theo chiều ngang khi khối có width.

Slide 41–42

Flexbox hay Grid

Flexbox sắp xếp phần tử theo một trục (một hàng hoặc một cột), phù hợp menu, nhóm nút. Grid sắp xếp theo hàng và cột cùng lúc, phù hợp danh sách card.

Tự kiểm tra. Menu đầu trang và mục Ghi nhớ nhanh nên dùng gì?

Menu dùng Flexbox (một hàng). Ghi nhớ nhanh dùng Grid (nhiều hàng, nhiều cột).
