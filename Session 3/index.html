Phần 1. CSS cơ bản

Slide 8

CSS là gì?

CSS (Cascading Style Sheets) là ngôn ngữ định dạng cho tài liệu HTML. HTML quyết định trang có nội dung gì; CSS quyết định nội dung đó trông như thế nào: màu sắc, font chữ, khoảng cách, bố cục.

Tách CSS ra file riêng giúp mã dễ quản lý: một file CSS dùng cho nhiều trang, đổi giao diện không cần sửa HTML.

Quan sát: trang bạn đang xem chưa có dòng CSS nào. Hãy nhớ trạng thái này để so sánh cuối buổi.

Slide 9

Ba cách thêm CSS vào trang

  1. Inline: viết trong thuộc tính style của từng thẻ. Nhanh nhưng khó bảo trì.
  2. Internal: viết trong thẻ <style> ở phần <head>. Chỉ dùng cho một trang.
  3. External: viết trong file .css riêng, liên kết bằng thẻ <link>. Đây là cách dùng trong môn học.
<!-- Inline -->
<p style="color: red;">Xin chào!</p>

<!-- Internal -->
<style>
  h1 { color: green; }
</style>

<!-- External -->
<link rel="stylesheet" href="css/style.css">

Dòng này dùng để thử inline CSS.

Slide 10 – 12

Quy tắc khai báo CSS

Mỗi quy tắc gồm bộ chọn (chọn phần tử nào) và khối khai báo trong ngoặc nhọn. Mỗi khai báo có dạng thuộc tính: giá trị;.

selector {
  property: value;
}

.card { padding: 1rem; color: #172033; }

Ba loại bộ chọn cơ bản: theo thẻ (p), theo class (.demo ứng với class="demo"), theo id (#intro ứng với id="intro").

Slide 13, 15

Bộ chọn và quy tắc xếp tầng

  • p: chọn tất cả đoạn văn trong trang.
  • .card: chọn mọi phần tử có class card, dùng lại được nhiều lần.
  • #contact: chọn đúng một phần tử có id contact (id là duy nhất).

Cascade (xếp tầng): hai quy tắc cùng bộ chọn, cùng thuộc tính thì quy tắc viết sau được áp dụng.

.card { color: blue; }
.card { color: navy; }   /* kết quả: navy */

Quan sát: thẻ Giới thiệu ở đầu trang (class card) và khối Liên hệ ở cuối trang (id contact).

Slide 14

Màu chữ và màu nền

color đổi màu chữ, background-color đổi màu nền. Bốn cách viết màu:

Tên màu – color: red;

HEX – color: #ffa400; (mỗi cặp ký tự từ 00 đến FF)

RGB – color: rgb(0, 0, 0); (mỗi kênh 0–255)

RGBA – color: rgba(0, 0, 0, 0.5); (alpha 0 trong suốt, 1 đục hoàn toàn)

Kích thước linh hoạt: rộng 100%, tối đa 600px, cao tối thiểu 120px

Slide 21

Viền và bo góc

Viết tắt border: độ-dày kiểu màu;, ví dụ border: 2px solid #3157d5;. Kiểu thường dùng: solid (liền), dashed (nét đứt), dotted (chấm). border-radius bo góc.

Quan sát: thẻ Giới thiệu ở đầu trang. Cùng làm: đổi solid thành dashed rồi đổi border-radius.

Slide 22

Margin – khoảng cách bên ngoài

Viết 1 đến 4 giá trị theo thứ tự trên – phải – dưới – trái:

margin: 16px;                 /* mọi phía */
margin: 16px 24px;            /* trên/dưới | trái/phải */
margin: 16px 24px 32px;       /* trên | trái/phải | dưới */
margin: 16px 24px 32px 40px;  /* trên | phải | dưới | trái */
margin: 16px auto;            /* căn giữa khối có width */

Margin dọc của hai khối liền nhau có thể gộp: 20px và 30px thành 30px, không phải 50px.

Slide 23

Padding – khoảng cách bên trong

Cách viết giống margin. Nền được vẽ trong vùng padding; margin nằm ngoài viền và luôn trong suốt.

Cùng làm: đổi padding của thẻ Giới thiệu thành 24px 12px và quan sát.

Slide 24

box-sizing: content-box và border-box

Cùng width: 200px; padding: 20px; border: 2px solid;:

  • content-box (mặc định): tổng rộng = 200 + 20 × 2 + 2 × 2 = 244px.
  • border-box: tổng rộng = 200px, phần nội dung = 200 − 40 − 4 = 156px.

border-box

Cùng làm: nếu padding tăng lên 30px, tính lại hai trường hợp rồi kiểm tra bằng DevTools.

Slide 25

Thuộc tính display

  • block: bắt đầu dòng mới, chiếm cả dòng.
  • inline: nằm trên dòng chữ; width/height không có tác dụng.
  • inline-block: nằm trên dòng, đặt được width/height.
  • none: không hiển thị, không chiếm chỗ.

Phần 2. Mô hình hộp và nguyên tắc giao diện

Slide 33

Mô hình hộp

Mỗi phần tử là một hộp gồm 4 lớp, từ trong ra ngoài: content → padding → border → margin. Padding là khoảng trong, margin là khoảng ngoài.

content

Chú thích: vùng vàng là margin, viền xanh đậm là border, vùng xanh nhạt là padding, vùng trắng là content.

Slide 34

Áp border-box cho toàn trang

*, *::before, *::after {
  box-sizing: border-box;
}

Sau quy tắc này, width khai báo đã bao gồm padding và border. Margin vẫn nằm ngoài width.

Khoảng cách dòng hợp lý (khoảng 1.5) giúp đoạn văn dễ đọc, nhất là khi phóng to trang.

Slide 37

Màu nền, màu chữ phù hợp

  • background: làm nền, tạo không gian cho nội dung.
  • text: chữ, tiêu đề, thông tin chính.
  • primary: thành phần chính như menu, nút bấm, tiêu đề mục.
  • accent: nhấn mạnh thông tin quan trọng, dùng ít.

Khai báo các màu này một lần thành biến (design token) và dùng lại bằng var():

:root {
  --text: #172033;
  --primary: #1f3c88;
}
body { color: var(--text); }

Phần 3. Bố cục trang

Slide 42

Flexbox và Grid

  • Flexbox: sắp theo một trục (một hàng hoặc một cột). Ví dụ: menu.
  • Grid: sắp theo hàng và cột (hai chiều). Ví dụ: danh sách card dự án.

Slide 43 – 45

Làm menu bằng Flexbox

display: flex đặt trên phần tử cha; các phần tử con xếp theo trục chính (main axis, mặc định nằm ngang). Trục phụ (cross axis) vuông góc với trục chính.

.site-nav {
  display: flex;
  flex-wrap: wrap;      /* cho phép xuống dòng khi hẹp */
  gap: .5rem 1rem;      /* khoảng cách hàng | cột */
  align-items: center;  /* căn theo trục phụ */
}

Quan sát: menu ở đầu trang. Thu hẹp cửa sổ đến khoảng 320px để kiểm tra.

Slide 46

Căn chỉnh với Flexbox

  • gap: khoảng cách giữa các item.
  • justify-content: phân bố item trên trục chính (flex-start, center, space-between).
  • align-items: căn item trên trục phụ (flex-start, center, flex-end).
